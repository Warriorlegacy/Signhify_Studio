## Deliverability Checklist

Before sending any campaign:

- [ ] SPF record configured for sending domain
- [ ] DKIM key added to DNS
- [ ] DMARC policy set (p=none initially, move to quarantine)
- [ ] From name set to "Piyush Raj Singh" (personal touch)
- [ ] Reply-to set individually (not a shared inbox)
- [ ] One-click unsubscribe header present (RFC 8058)
- [ ] Physical address in footer (Noida, UP, India)
- [ ] Plain text AND HTML version (some prospects block images)
- [ ] Sending volume < 50/day per warm-up address (start at 10/day)
