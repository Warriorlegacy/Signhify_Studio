## 1. EXECUTIVE SUMMARY

Signhify.online is not a freelancer portfolio. It is not a standard agency website.

It is the **front door of a future AI Product Ecosystem** — designed from Day 1 to evolve from a premium AI engineering studio (2026) into India's leading AI product creation platform (2030+).

The website must do three things simultaneously:

1. **Earn trust and generate leads** — today, as an AI Engineering Studio
2. **Signal the future** — tomorrow, as a vibe-coding and AI product platform
3. **Feel cinematic** — always, like a product from Apple, Vercel, or Linear

> **North Star:** "Describe your idea. Signhify builds it."

### What makes this different

| Typical Agency Website    | Signhify.online                          |
| ------------------------- | ---------------------------------------- |
| Services page + portfolio | Cinematic experience + product ecosystem |
| "We do web design"        | "We build digital businesses with AI"    |
| Static screenshots        | Animated case studies with metrics       |
| Contact form              | Lead qualification wizard + Calendly     |
| No future vision          | Visible 5-year product roadmap           |
| Looks like a freelancer   | Looks like a YC-backed startup           |

## 6. ANIMATION & MOTION SYSTEM

This is the most critical differentiator from standard agency sites. Every interaction must feel intentional.

### Animation Libraries

| Library              | Purpose                                      |
| -------------------- | -------------------------------------------- |
| Framer Motion        | Component-level animations, page transitions |
| GSAP + ScrollTrigger | Complex scroll storytelling, pinning         |
| Three.js             | 3D hero background, particle systems         |
| Lenis                | Smooth scroll (critical for cinematic feel)  |
| Motion One           | Lightweight micro-interactions               |

### Motion Principles

1. **Entrance animations:** Fade-up + slight Y offset (0→0, 20px→0), 0.6s ease
2. **Stagger:** 0.1s delay between sibling elements
3. **Scroll triggers:** Start at 80% viewport, end at 20%
4. **Hover states:** 200ms max, never jarring
5. **Page transitions:** Horizontal wipe or fade with brand color flash

### Hero Background Specification (Three.js Scene)

```javascript
// Particle system: ~2000 floating nodes
// Connected by thin lines when within 150px distance
// Base color: rgba(255,107,0,0.3) → rgba(255,159,28,0.1)
// Movement: slow drift with noise-based velocity
// Mouse interaction: particles repel from cursor (radius 200px)
// Scroll reaction: scene rotates on Z-axis as user scrolls
// Grid overlay: infinite perspective grid, fades to edges
// Performance: use InstancedMesh, cap at 60fps
```

### Scroll Storytelling Spec

```
Viewport Position | Animation Trigger
--------------------------------------------
Hero (0%)         | Particle system active, headline types in
25% scroll        | Stats counter animates up
40% scroll        | Project cards slide in from alternating sides
55% scroll        | Service cards fan open
65% scroll        | Roadmap timeline draws itself
75% scroll        | Founder section parallax image
85% scroll        | Testimonials fade in sequence
95% scroll        | CTA section glows, pulsates
```

### Text Animations

```
Hero Headline:   Word-by-word reveal, 60ms stagger
Section Heads:   Single reveal, fade+up from 30px below
Body Text:       Line-by-line reveal on scroll
Stats:           Count-up animation (0 to final, 1.5s)
Code snippets:   Typewriter effect, cursor blinks
```

## 14. PERFORMANCE REQUIREMENTS

### Targets

| Metric                          | Target  | Measurement             |
| ------------------------------- | ------- | ----------------------- |
| Lighthouse Performance          | 95+     | PageSpeed Insights      |
| LCP (Largest Contentful Paint)  | < 2.5s  | Core Web Vitals         |

| First Load JS Bundle            | < 250KB | Next.js bundle analyzer |
| Time to Interactive             | < 3.5s  | Lighthouse              |

### Optimization Strategy

```
□ Three.js: Lazy load, only on hero — not loaded for other pages
□ Images: All via Next.js <Image>, WebP + AVIF, lazy loaded below fold
□ Fonts: Self-hosted, subset, preloaded
□ Animations: Respect prefers-reduced-motion media query
□ Videos: Hosted on Cloudflare Stream (not stored in repo)
□ Code splitting: Dynamic imports for heavy components
□ ISR: Sanity CMS pages use Incremental Static Regeneration (60s revalidation)
```
