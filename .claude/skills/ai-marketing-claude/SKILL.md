# AI Marketing Suite

15 marketing skills for a complete marketing department in one tool. Commands via `/market <subcommand>`.

## Commands

| Command | What it does |
|---------|-------------|
| `/market audit <url>` | Full marketing audit — 5 parallel subagents, 0-100 score, revenue-impact recommendations |
| `/market copy <brief>` | Copywriting with PAS/AIDA/Before-After-Bridge, before/after pairs + swipe file |
| `/market emails <brief>` | Email sequences: welcome, nurture, launch, cart abandon, cold outreach |
| `/market social <brief>` | 30-day social calendar across 2-3 platforms with hook formulas |
| `/market ads <brief>` | Platform-specific ad campaigns (Google, Meta, LinkedIn, TikTok, X) |
| `/market funnel <url>` | Sales funnel mapping, drop-off analysis, revenue lift estimates |
| `/market competitors <url>` | Competitive intel: feature matrices, SWOT per competitor, steal-worthy tactics |
| `/market landing <url>` | 7-point CRO analysis + form audit + A/B test hypotheses |
| `/market launch <brief>` | 8-week launch playbook with email, social, media, partner templates |
| `/market report <url>` | 6-category marketing report with 30-60-90 day roadmap |
| `/market seo <url>` | On-page SEO audit + E-E-A-T + technical + gap analysis |
| `/market brand <brief>` | Brand voice mapping, archetype, do/don't guide, copy samples |
| `/market proposal <brief>` | 10-section client proposal with pricing psychology |
| `/market report-pdf <url>` | Generate a branded 5-7 page PDF report |

## Marketing Audit (flagship)

5 parallel subagents: content, conversion, competitive, technical, strategy → composite score + prioritized action plan.
